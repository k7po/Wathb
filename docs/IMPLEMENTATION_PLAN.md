## بوابة ما قبل P1 (مراجعة المستخدم)

1. الموافقة على هذه الوثائق والنطاق النهائي والهوية البصرية الرقمية أعلاه.
2. الحد الأدنى المعتمد Android API 26 وiOS 15. يلزم التحقق من توافق المكتبات والبناء الفعلي معهما؛ لا يعني الاختيار أن iOS اختُبر على هذا الجهاز.
3. لا يلزم إعداد Supabase في P1؛ قبل P2 يختار المستخدم المشروع والمنطقة/الخطة ويضبطه بنفسه دون مشاركة أسرار.
4. يمكن تأجيل الخرائط وpush إلى المرحلة التي تستخدمهما؛ يبقى إدخال العنوان يدويًا وصندوق الإشعارات الداخلي صالحين.
5. قبول الافتراضات اللازمة لـ P1؛ تُحسم قواعد السعة والحضور والنتائج وأهلية التقييم عند بوابتي P4 وP5 كما هو محدد في قسم القرارات أدناه.
6. اجتازت بيئة Flutter وAndroid فحوصها الموثقة أدناه. إنشاء Git commit تأسيسي للوثائق و`.gitignore` قبل ملفات التطبيق؛ لا يبدأ الكود قبل موافقة المستخدم.

## قرارات منتج يجب أن تحسم قبل المجال المعني

- **السعة بعد القبول وقائمة الانتظار (قبل P4):** يختار المستخدم سلوك خفض السعة إذا تجاوزها عدد المقبولين، ويقرر ما إذا كانت قائمة الانتظار ضمن النطاق؛ لا تتجاوز المعاملة السعة في أي خيار.
- **الحضور (قبل P5):** يختار المستخدم من يثبت الحضور وما الأدلة المقبولة وحق الاعتراض ومدته ومسار التصحيح. لا يتساوى القبول بالحضور.
- **النتيجة (قبل P5):** يحدد المستخدم صلاحية الإرسال والتأكيد، مهلة الاعتراض والتحكيم والتصحيح؛ لا تؤثر نتيجة غير مؤكدة في المسيرة.
- **المستوى/التوازن:** اختياري ومصدره معلن؛ لا ترتيب مهارة أو توصية متوازنة قبل بيانات ومعيار معتمد.
- **التعليقات (قبل P4):** يحدد المستخدم الجمهور، مهلة التعديل، الإخفاء، وإجراءات الإبلاغ والإشراف؛ تظل التعليقات مرتبطة بالنشاط.
- **التقييم (قبل P5):** يحدد المستخدم المقياس ومعايير تقييم اللاعب والملعب، نافذة الإرسال والنشر والتظلم وظهور الهوية وأدلة أهلية زيارة الملعب؛ المنع من التكرار والأهلية مثبتان تقنيًا.
- **البلد والعمر والاحتفاظ:** افتراض السعودية/عربي أولًا مؤقت؛ حد العمر/الموافقة والنص القانوني ومواعيد حذف/تصدير تتطلب مراجعة قبل الإطلاق.
- **التذكيرات والإشعارات (قبل P4):** يحدد المستخدم وقت/عدد التذكيرات، النافذة الهادئة، التفضيلات، وما إذا كان push مفعلًا؛ منع التكرار واحترام المنطقة الزمنية متطلبان ثابتان.
- **تكرار النشاط (قبل P4):** اعتماد حدود قاعدة التكرار، أفق توليد النسخ، وقاعدة تعديل المستقبل والنسخة المنفذة.
- **مزود الملاعب (قبل خرائط P5):** اختيار مزود الخرائط/الترميز الجغرافي وسياسة الموقع؛ إلى حينه يعمل الدليل بعنوان/رابط يدوي دون ادعاء خرائط متصلة.
- **المزودات:** Supabase، خرائط/geocoding، push، تخزين الصور، بريد تأكيد، تسجيل اجتماعي، متجر؛ تتطلب إعدادًا وحسابات وسياسات. لا نفترض اتصالًا حاليًا.
