# WATHB (وثب) — متطلبات المنتج

> **المعيار المعتمد (إصدار موحّد 1.0، 2026-10-28):** هذه الوثيقة تحدد نطاق المنتج النهائي وتجربة الاستخدام والهوية المعتمدة. المراحل تؤثر في ترتيب التسليم فقط ولا تسقط أي وظيفة من النطاق.

## النطاق النهائي

منتج رياضي اجتماعي متعدد الرياضات، عربي أولًا مع الإنجليزية، Android وiOS، لتنظيم المباريات والأنشطة، جمع اللاعبين، إدارة الدعوات والردود والتعليقات، تشكيل الفرق، توثيق الحضور والنتائج، بناء مسيرة رياضية، التقييمات، دليل الملاعب، والإشعارات والخصوصية. لا ادعاء بوجود خدمة خارجية قبل إعدادها والتحقق منها.

الحد الأدنى المستهدف للمنصات: Android API 26 وiOS 15. يجب التحقق من توافق إصدارات Flutter والمكتبات والبناء الفعلي مع هذين الحدين قبل تثبيت الاعتماديات أو اعتماد الإصدار.

### الوظائف الملزمة في المنتج النهائي

1. **الحساب:** بريد وكلمة مرور، تأكيد واستعادة، إدارة الجلسات والخروج، حذف/تصدير الحساب حسب السياسة، وبنية موثقة لإضافة Google وApple. لا تسجيل اجتماعي قبل ضبط مزوديه.
2. **الملف والعلاقات:** ملف وصورة اختيارية ورياضات/مراكز وبيانات اختيارية وخصوصية لكل حقل؛ طلبات صداقة واردة وصادرة وقبول/رفض/إزالة وحظر وإبلاغ.
3. **النشاط:** إنشاء/تحرير/نشر/إلغاء مباراة أو نشاط متعدد الرياضات، موعد ومنطقة زمنية وموقع وسعة وتفاصيل؛ دعوات، قبول/رفض/انسحاب، تعليق مرتبط بالنشاط مع إشراف وإبلاغ، قائمة حالات، ومشاركة رابط دعوة مضبوط الصلاحية.
4. **التكرار:** سلسلة بقواعد محدودة ونهاية، ونسخة مستقلة لكل موعد؛ إدارة نسخة أو المستقبل من السلسلة مع حماية النسخ المنفذة/المقفلة.
5. **الفرق:** عشوائي، يدوي، ومراعٍ للمراكز عند توفرها؛ بيانات ناقصة واضحة؛ إعادة توزيع وتعديلات يدوية؛ تحقق دائم من عدم ضياع لاعب أو تكراره.
6. **المسيرة والنتائج:** سجل مشاركة بعد تأكيد الحضور فقط، ونتيجة بعد تأكيد موثوق مع اعتراض/تصحيح مدقق؛ إحصاءات قابلة لإعادة الحساب من مصادرها.
7. **التقييم:** تقييم لاعب بعد نشاط مشترك وحضور مثبت، وتقييم ملعب بعد زيارة/حجز/مشاركة مستوفية؛ منع التكرار، نافذة زمنية وسياسة إشراف/بلاغ.
8. **الملاعب:** دليل بحث وتفاصيل وموقع وتقييمات متحققة عند توفرها؛ الحجز والدفع خارج النطاق حتى قرار وتكامل صريح.
9. **الإشعار:** صندوق داخلي دائم، تفضيلات حسب النوع والقناة، حالات قراءة، منع تكرار، روابط عميقة، تذكير مجدول، وpush عبر مزود خارجي بعد إعداده. تتضمن أنواعًا للدعوة والرد والتغيير والإلغاء والتعليق والنتيجة/التقييم والتذكير والإشراف.
10. **الإعداد:** الملف والخصوصية والحظر والإشعارات واللغة والثيم والجلسات والحساب والشروط وسياسة الخصوصية.

## الأدوار والصلاحيات وتجربة الشاشات

- **زائر:** دخول/تسجيل/استعادة؛ لا يرى بيانات مقيدة.
- **لاعب/مدعو/مشارك:** الرئيسية؛ اكتشاف وبحث؛ تفاصيل نشاط عام ودعوة خاصة للمستلم؛ أنشطتي (قادم/سابق/ملغى)؛ قبول/رفض/انسحاب وتعليق مسموح؛ تشكيلات؛ المسيرة؛ الملاعب؛ الإشعارات؛ الملف والأصدقاء والإعدادات. يرى فقط البيانات المسموحة له.
- **منظّم:** كل ما سبق مع إنشاء/تحرير/إلغاء؛ دعوة؛ إدارة حالات المشاركين والسعة؛ نشر التعليقات/إخفاؤها ضمن قواعد معلنة؛ توزيع الفرق؛ إدخال الحضور والنتيجة وإرسالها للتأكيد. لا يختلق تقييم حضور أو يعدل تقييمًا.
- **مشرف منصة:** لوحة/قائمة بلاغات، أهداف البلاغ وسياق محدود، إخفاء محتوى وإجراءات معللة واستئناف/تدقيق. لا يكتسب صلاحيات مستخدم عادية عبر تطبيق العميل.
- **الشاشات المشتركة:** لكل قائمة/تفصيل/نموذج حالات تحميل، فراغ مع إجراء مناسب، خطأ مع إعادة محاولة عند الإمكان، نجاح مؤكد، وحالة عدم صلاحية. حماية إعادة الإرسال وشرح تعارض المقاعد.
- مسارات: الحساب → الرئيسية؛ الرئيسية → تفاصيل → استجابة/تعليق/مشاركة؛ إنشاء → معاينة → نشر → دعوة؛ تفاصيل → فرق/نتيجة/حضور؛ أنشطتي → سجل؛ اكتشاف → ملف/طلب صداقة أو ملعب؛ الإشعار → الكيان؛ الحساب → إعدادات/خصوصية/حذف.

## الهوية البصرية المعتمدة

- الاتجاه: رياضي راقٍ هادئ، خلفيات محايدة، أخضر عميق للحركة الأساسية، فيروزي/نعناعي للتمييز، وألوان حالة مستقلة؛ لا توهج/تدرج زخرفي ولا صور أو بيانات وهمية.
- **ألوان Light:** background `#F6F8F7`، surface `#FFFFFF`، surfaceVariant `#E9EFEC`، primary `#0B6B4B`، onPrimary `#FFFFFF`، secondary `#147D82`، accent `#B8F2D5`، text `#17231E`، muted `#5D6B64`، outline `#D5DED9`، error `#B42318`، warning `#8A5A00`، success `#16794A`.
- **ألوان Dark:** background `#101714`، surface `#18211C`، surfaceVariant `#222E27`، primary `#63D6A2`، onPrimary `#092318`، secondary `#67C7C2`، accent `#285C46`، text `#E7F0EA`، muted `#A7B7AE`، outline `#39483F`، error `#FF8A80`، warning `#F2C66D`، success `#7CE0A7`.
- قواعد: الألوان عبر semantic tokens فقط؛ تباين WCAG AA للنصوص وعناصر التحكم؛ اللون ليس الإشارة الوحيدة؛ الحالات تستخدم رمزًا ونصًا. لا استخدام `accent` كلون نص صغير.
- الخط: **IBM Plex Sans Arabic** (أوزان 400/500/600/700) للنصوص والعناوين العربية؛ **Inter** للأرقام والنص الإنجليزي عند توفره؛ fallback بخط النظام. تُرفق الخطوط المرخصة ضمن الأصول بعد فحص الترخيص.
- الأيقونات: مجموعة واحدة متسقة (Material Symbols Rounded بوزن/حجم ثابتين)، مع تسميات لقارئ الشاشة؛ لا خلط رموز emoji في التنقل.
- الشبكة: مقياس مسافات 4/8/12/16/24/32، نصف قطر 8 للحقول و12 للبطاقات و16 للحوارات، ارتفاع لمس مستهدف ≥48dp، حواف آمنة وشاشات مرنة. RTL حقيقي باستخدام start/end وتدفق عربي، مع عكس اتجاهات الحركة المناسبة لا الأيقونات غير الاتجاهية.
- الثيم يتبع النظام افتراضيًا ويتيح فاتح/داكن/النظام؛ نفس الرموز والمكونات والدلالات في كل الشاشات.
